# EXCEL QUEST OS — ASSET PACK FINAL

## Art direction
Professional manufacturing × spreadsheet × mission-control. Dark navy base, safety-yellow highlights, cool blue data accents. The visual language is energetic but intentionally avoids a childish game aesthetic.

## Included
- 1 master art board
- 9 implementation-ready visual crops: hero, characters, badges/icons, environments, UI, screen samples, demo frames, 30-second Rescue UI, audio guide
- 7 lightweight mono WAV UI sound effects
- 3 Japanese AI narration references/transcripts

## Recommended use
Hero: top/entry screen. Characters: guide, support, bot. Screen examples: implementation reference rather than literal screenshots. Demo frames: shortcut animation reference. Sound defaults OFF. Keep voice optional and event-based only.

## Important implementation note
The generated master contains stylized spreadsheet/Excel-like visual language. For production, build actual text/buttons in HTML/CSS rather than rasterizing UI labels, ensuring legibility, accessibility, and easy correction.
