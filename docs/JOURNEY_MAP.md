# Journey Map 検証レポート

要件定義 §4（TARGET EXPERIENCE）と §29（最終 Journey）を、3つのペルソナで実際に通して検証し、見つかった問題を修正した記録です。

- 再現方法：`npx http-server -p 8123 . &` を起動してから `node tests/journey.mjs`（引数 `mouse` / `keyboard` / `novice` で1人だけ実行）
- 計測方法：Playwright で実際のキー・マウス操作を送っています。問題文を読む時間として 1.8 秒を入れています。
- 注意：自動操作は人間より速いので、時間の値は**下限の目安**です。実際の受講者でもう一度測る必要があります（末尾の「未検証の項目」）。

## ペルソナ

| ID | 人物像（§3） | 操作のしかた |
|---|---|---|
| mouse | 「マウスでもできる」中級者 | スクロールバーのドラッグ、Shift+クリック、リボン、ドロップダウン。今日の技を知った後はキーを使う |
| keyboard | すでにショートカットを使える人 | 最初からキー操作 |
| novice | 「間違えるのが怖い」初級者 | 診断では手が止まり、AHA も「あとで」。練習ではヒントを最後まで見てスキップ |

## 見つかった問題と修正

重大度は、Journey の成功状態（§30：「速くなった。困ったらまた使いたい」）にどれだけ響くかで付けています。

| # | ステージ | 見つけたペルソナ | 問題 | 重大度 | 修正 |

## 未検証の項目（実際の受講者で確認すべきこと）

1. **時間の実測**：自動操作は人間より速いため、受講者で初回 Speed-Up までの時間（目標60秒以内）と FAST の所要時間（目標約3分）を測る。記録画面から JSON を書き出して集計できます。
2. **ブラウザが先に取るキー**：社内標準ブラウザで Ctrl+H／Ctrl+D／Ctrl+F が横取りされないか。Mac は ⌘ で代わりになります。
3. **QR の受け渡し**：ページを社内サーバー等で公開したときにだけ有効です（localhost やファイル直開きではスマホから届かず、画面にもそう表示します）。
4. **翌日・1週間の回答**：「使えた」は自己申告です。研修担当者が使用状況を実際に観察する場合は別途の運用が必要です。
