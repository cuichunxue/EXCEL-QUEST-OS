User Journey Analysis · v2.0 MVP

受講者ジャーニー分析

製造・品質・技術・事務の初級〜中級者が、研修の案内を受けてから1週間後まで、何をして、何を思い、どこで離れかけるか。アプリの外も含めて15の場面に分けて分析しました。

対象：EXCEL QUEST OS（ブランチ claude/excel-quest-os-mvp）2026-10-04根拠：実操作シミュレーション3人分＋全18画面の計測

00結論

アプリの中の流れは、要件の Journey どおりに一周できます（前回の検証で17件を修正済み）。今回の分析では、残っている大きなリスクの多くがアプリの外と画面の言葉にあることが分かりました。

  1. 1
    いちばん大事な瞬間はアプリの外にある翌日、本物の Excel で初めて使うときです。ここでつまずくと「研修だけの技」になります。たとえば完全一致のチェックは、本物の Excel では「オプション(T) >>」の中に隠れていますが、シミュレーターでは最初から見えています。
  2. 2
    英語ラベルが、対象者との距離を作っているミッション一覧に8個、結果画面に7個、診断結果に7個の英語ラベルがあります（BOTTLENECK、CHALLENGE、CALCULATE など）。「自分向けではない」「ゲームっぽい」と感じさせる入口になりえます。
  3. 3
    いちばん疲れている終盤に、いちばん文字が多いBEFORE/AFTER は407字、診断結果は355字で、全画面の中で1位と2位です。記憶に残る「最後の印象」がいちばん重い画面になっています。
  4. 4
    スマホでは主ボタンが1画面目に入らないiPhone SE ではボタンの上端が644px（画面の高さは568px）、iPhone 13 でも下端が680px（画面664px）です。困ったときに開く 30秒RESCUE も、SE では7項目のうち3つしか見えません。
  5. 5
    入口と再訪を本人の記憶に頼っている「また研修？」という気持ちは案内を受けた時点で生まれますが、案内文はプロダクトの範囲外です。困った瞬間に戻ってくる道も、URL を覚えていることが前提です。研修担当者が効果をまとめて見る手段もありません。

01人物像

要件 §3 の人物像に、前回の操作シミュレーションで観察した3つの型を重ねました。4人目の研修担当者は、受講者の Journey を外から支える立場として入れています。

品質保証・中級

マウス派｜検査記録を毎日 Excel で扱うマウスでもできるし、困ってはいない
  • スクロールとドラッグは速い
  • キーを知れば最も伸びる層
  • シミュレーション：診断22秒、FAST 37秒

生産管理・上級寄り

キーボード派｜ショートカットは一通り使える知ってることばかりだったら時間のムダ
  • 新しく学べるのは落とし穴の知識
  • 前回の修正で、全部🟢なら CHALLENGE を推奨
  • シミュレーション：FINAL で BEFORE より遅い結果も出た

総務・事務・初級

初心者｜Excel は入力中心間違えるのが怖い。ついていけるかな
  • 診断で手が止まる → 前回の修正で33秒で抜けられるように
  • 答えを見てから自分でやる流れ
  • 翌日、ひとりで本物の Excel を使う場面が最難関

研修担当者

受講者の外側｜案内・効果測定受けさせた効果を、上に数字で説明したい
  • 案内文と URL の配布を担う
  • 記録は各受講者のブラウザの中にしかない
  • KPI はひとりずつ JSON を書き出して集める必要がある

04決定的な瞬間

ここで印象が決まり、続けるか離れるかが分かれる場面です。現状の対応の度合いを付けました。

MoT 1 · 開始から10秒

「研修じゃない」と思えるか

アプリ内は、ボタン1つで2秒以内にシミュレーターが表示されます。ただし受講者の気持ちは、案内メールを読んだ時点ですでに決まり始めています。

アプリ内：対応済み案内：範囲外
MoT 2 · 開始から60秒以内

初めての SPEED UP

マウス派は2.5秒→1.1秒で、キーボード派も「もう速い」と認められます。一方、初心者で「あとで」を選んだ人は、この体験を持たないまま診断を終えます。

マウス派・キーボード派初心者：取りこぼしあり
MoT 3 · 練習の2回目

落とし穴を「失敗」でなく「発見」と感じるか

減点はせず、読んでいる間はタイマーも止まります。ただ見出しが「REAL EXCEL TRAP」「DISCOVERY」と英語で、初心者は言葉の意味が取れないまま次へ進む可能性があります。

仕組み：対応済み言葉：改善余地
MoT 4 · 翌日の業務中

本物の Excel で初めて使う

ここで成功すれば「研修の技」が「自分の技」になり、失敗すれば忘れます。置換の完全一致が見つからない差は、まさにこの瞬間に出ます。プロダクトがその場にいない、最大の空白です。

プロダクトの外・最重要
MoT 5 · 困った瞬間

「またここを使いたい」と思い出せるか

要件 §30 の成功状態そのものです。RESCUE の中身は2クリックで届きますが、そこへ戻る道（URL・お気に入り・スマホ）を受講者が持っていなければ始まりません。

中身：対応済み戻る道：弱い

07実際の受講者で確かめること

仮説

  1. 感情の最も低い点は「翌日、本物の Excel で使う」場面である
  2. 英語ラベルを日本語主にすると、初級者の FAST 完了率が上がる
  3. 初心者の半数以上が AHA を「あとで」にする
  4. 前後比較の画面で、工程の表まで読む人は少ない
  5. スマホからの RESCUE 再訪は、QR で取り込んだ人に偏る

確かめ方（5〜8人で足ります）

  • 受講の観察：各職種から1〜2人。画面を見ながら声に出してもらい、止まった場所と言葉を記録
  • 翌日の聞き取り：「どの技を、どのファイルで、うまくいったか」を5分
  • 記録の回収：記録画面の JSON 書き出しで、Time to First Speed-Up・ヒント依存率・翌日使用を集計
  • 1週間後：RESCUE を開いた回数と、そのきっかけ
分析の根拠：tests/journey.mjs（3人分の実操作シミュレーション）、全18画面の自動計測、端末3機種の1画面目の計測。感情スコアは観察からの推定で、実際の受講者のデータではありません。自動操作は人間より速いため、時間は下限の目安です。
